
# FitLog — Workout Library

FitLog is a modern, responsive workout library application designed to help users explore exercises, create a personal workout plan, and track their fitness progress. It features a clean dark interface with a lime-green accent color.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Toastify
- Context API
- Browser Local Storage
- REST API

## ✨ Key Features

1. **Workout Library** — Browse workout exercises and explore workout details.
2. **Workout Details** — View exercise information, including target muscles, equipment, and instructions.
3. **My Plan** — Add exercises to a personal workout plan and manage selected workouts.
4. **Workout Tracking** — Mark workouts as completed, save exercises, and remove them from your plan.
5. **Responsive Design** — Enjoy a clean, dark-themed interface across desktop, tablet, and mobile devices.
